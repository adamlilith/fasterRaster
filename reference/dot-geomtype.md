# Get geometry type from the sources() name of a vector

Get geometry type from the sources() name of a vector

## Usage

``` r
.geomtype(x)
```

## Arguments

- x:

  A `GVector` or the
  [`sources()`](https://github.com/adamlilith/fasterRaster/reference/sources.md)
  name of one.

## Value

Character ("point", "line", or "area"; i.e., in **GRASS** nomenclature).
