# Count number of levels from a data.frame/table, list, or SpatRaster

Counts number of levels in a character string (specifically, the empty
string `""`), a `data.frame`, `data.table`, or list of `data.frame`s or
`data.table`s or empty strings.

## Usage

``` r
.nlevels(x)
```

## Arguments

- x:

  A `GRaster`, `SpatRaster`, *or* a `data.frame`, `data.table`, an empty
  string, or a list thereof.
