# Plot using a G-object's [`sources()`](https://github.com/adamlilith/fasterRaster/reference/sources.md) name

Plot using a G-object's
[`sources()`](https://github.com/adamlilith/fasterRaster/reference/sources.md)
name

## Usage

``` r
.plot(x, ...)
```

## Arguments

- x:

  The
  [`sources()`](https://github.com/adamlilith/fasterRaster/reference/sources.md)
  name of a `GRaster` or `GVector`

- ...:

  Other arguments to pass to
  [`plot()`](https://github.com/adamlilith/fasterRaster/reference/plot.md).
